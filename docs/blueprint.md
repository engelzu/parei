# **App Name**: PlanilhaFlex

## Core Features:

- Data Presentation: Display data fetched from a Google Sheet in a sortable, searchable, and filterable table.
- Inline Editing: Allow users to adjust values (such as 'AVANÇO') directly in the table.
- Data Synchronization: Enable saving the modified data back to the original Google Sheet via Google Apps Script.
- Mobile friendly display: Enable mobile-responsive design.

## Style Guidelines:

- Primary color: HSL(141, 68%, 45%) - A vibrant green (#2EC973) evokes efficiency and action.
- Background color: HSL(141, 14%, 94%) - A very light green (#F0FAF3) that keeps the UI light and unobtrusive.
- Accent color: HSL(111, 65%, 62%) - A bright yellow-green (#9DE357) provides visual contrast, drawing attention to interactive elements without being distracting.
- Font choice: 'Inter' (sans-serif) for both headings and body text. Note: currently only Google Fonts are supported.
- Use Font Awesome icons for actions like filtering, saving, and exporting.
- Maintain a clean and spacious layout with clear visual hierarchy for easy data scanning.
- Incorporate subtle transitions for interactive elements, such as highlighting a row on hover.
